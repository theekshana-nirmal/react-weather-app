# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public issue. Instead, contact the maintainer directly to report it privately.

You can reach out via email: **your-email@example.com**  
*(Replace this with your actual email address or preferred contact method.)*

We take all security concerns seriously and will review your report as quickly as possible. Responsible disclosure is appreciated and helps keep the community safe.

## Supported Versions

This is a learning project and does not yet support versioned releases.  
All fixes and updates will be applied to the `main` branch.

| Version | Supported |  
|---------|-----------|  
| main    | ✅        |  
| others  | ❌        |  

## Recommendations

- Do **not** expose your API key publicly (e.g., don't commit `.env` files).
- Rotate or regenerate your API key if it is accidentally exposed.
- Keep dependencies up-to-date using `npm update` and monitor for vulnerabilities.
