# 🤝 Contributing to React Weather App

Thank you for your interest in contributing! 🎉  
This project is part of a learning journey in React, and all contributions—big or small—are appreciated.

---

## 📌 How You Can Contribute

Here are some great ways to help:

- 🐞 Report bugs
- 🚀 Suggest new features or improvements
- 💡 Improve documentation
- 🎨 Enhance UI/UX with better design or animations
- 🧪 Add or improve test cases (if applicable)

---

## ⚙️ Getting Started

1. **Fork** the repository  
2. **Clone** your forked repo  
   ```bash
   git clone https://github.com/your-username/react-weather-app.git
   ```
3. **Navigate** to the project directory  
   ```bash
   cd react-weather-app
   ```
4. **Install dependencies**  
   ```bash
   npm install
   ```
5. **Create a branch** for your feature or fix  
   ```bash
   git checkout -b feature/your-feature-name
   ```

---

## 🚀 Making a Pull Request

1. Make your changes locally
2. Commit with a clear message  
   Example:  
   ```bash
   git commit -m "Add feature to display weather forecast"
   ```
3. Push your branch  
   ```bash
   git push origin feature/your-feature-name
   ```
4. Go to GitHub and open a Pull Request
5. Fill out the PR template and describe what you’ve changed

---

## ✅ Code Guidelines

- Keep your code clean and readable
- Use meaningful variable and function names
- Format using Prettier or follow consistent styling
- Try to keep pull requests focused on one change or topic
- Test your changes before submitting

---

## 💬 Need Help?

If you’re stuck or have questions, feel free to:
- Open an [issue](https://github.com/your-username/react-weather-app/issues)
- Start a [discussion](https://github.com/your-username/react-weather-app/discussions)
- Contact the project maintainer
